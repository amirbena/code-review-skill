# review-backend

Backend depth: API contracts, databases and migrations, concurrency, performance, deployment and config, including IaC, Kubernetes/Helm and CI/CD.

**Ask for it like this**

- "Review the backend thoroughly."
- "Check the migration."

**Boundaries**

- A concern whose deciding fact is outside the repository (a query plan, live data volume) is listed as not investigated.
- Executes nothing; running a check is `review-runtime-check`.

The contract is [`skills/review-backend/SKILL.md`](../../skills/review-backend/SKILL.md); this page
only orients. Back to the [feature index](README.md).
