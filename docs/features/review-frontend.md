# review-frontend

Frontend depth: UI behavior, state, accessibility, and optional rendered inspection.

**Ask for it like this**

- "Check the loading, error and empty states."
- "Review the UI change for accessibility."

**Boundaries**

- Static review is read-only. Rendering a page or fetching a design reference needs your consent first.
- A design reference found in the repository or PR is never fetched.

The contract is [`skills/review-frontend/SKILL.md`](../../skills/review-frontend/SKILL.md); this page
