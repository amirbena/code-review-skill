# review-security

Security depth: auth, injection, secrets, crypto, trust boundaries and dependency or supply-chain changes.

**Ask for it like this**

- "Is this auth change safe?"
- "Review the dependency upgrade for supply-chain risk."

**Boundaries**

- Reports only traced evidence from code it read; generic advice is not a finding.
- Executes and renders nothing.
